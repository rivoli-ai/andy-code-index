# Insights

Insights provide deep analytical layers over your codebase, generated by LLM analysis. They go beyond simple documentation to reveal patterns, risks, and opportunities across your code.

## Overview

CodeIndex generates 11 distinct insight layers, each focusing on a different aspect of code quality and architecture. Insights are generated per repository and can be refreshed as code evolves.

## Insight Layers

### 1. Architecture Overview

Maps the high-level structure of your project: modules, packages, entry points, and their relationships.

### 2. Dependency Analysis

Identifies internal and external dependencies, circular references, and tightly coupled components.

### 3. Code Complexity

Highlights files and functions with high cyclomatic complexity, deep nesting, or excessive length.

### 4. Security Patterns

Scans for common security anti-patterns: hardcoded secrets, SQL injection risks, insecure defaults.

### 5. Error Handling

Evaluates error handling coverage: uncaught exceptions, empty catch blocks, missing validation.

### 6. Testing Coverage

Analyzes test file distribution, test-to-code ratios, and identifies untested modules.

### 7. API Surface

Documents public APIs, endpoint patterns, request/response schemas, and versioning.

### 8. Data Flow

Traces how data moves through the application: inputs, transformations, storage, and outputs.

### 9. Performance Patterns

Identifies potential performance issues: N+1 queries, unbounded loops, memory leaks.

### 10. Documentation Quality

Assesses inline documentation, README completeness, and comment-to-code ratios.

### 11. Technical Debt

Flags TODO/FIXME comments, deprecated usage, outdated patterns, and migration opportunities.

## Generating Insights

1. Navigate to **Discover**.
2. Select a repository.
3. Choose which insight layers to generate.
4. Click **Generate Insights**.

Generation uses the LLM key configured in [Settings](settings).

## Methodology

Each insight layer follows a structured process:

1. **File selection** -- Relevant files are identified based on the layer type.
2. **Chunked analysis** -- Files are sent to the LLM in batches to stay within context limits.
3. **Aggregation** -- Individual analyses are combined into a cohesive report.
4. **Scoring** -- Each layer produces a health score from 0 to 100.

## Viewing Results

Insight results are displayed as interactive cards on the Discover page. Each card shows:

- Layer name and health score
- Key findings summary
- Detailed recommendations
- Affected files with links

## Refreshing Insights

Re-generate insights after significant code changes to keep analysis current. Previous results are archived for comparison.
